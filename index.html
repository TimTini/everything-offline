Everything Offline

A collection of browser apps built from the Everything Project sources for this static GitHub Pages demo.

Cloud services are disabled.

Files and settings in an app session are in memory and are lost when you reload or close the tab. Export anything you need to keep.

GitHub Pages loads these app files from GitHub. This page has no launcher proxy and does not provide OS-level network isolation or a zero-outbound guarantee. Use the local offline launcher for its dedicated browser and deny-all proxy.
